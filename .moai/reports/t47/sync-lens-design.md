## 질문별 답

**(1) 한국어 문안.** 캡션 `'{q}' 검색 결과예요. 맞는 곳을 고르거나, 없으면 다른 이름으로 검색해 주세요.`(`:886`)는 해요체로 자연스럽고, 따옴표 바로 뒤에 받침 따라 바뀌는 조사가 없다('강남역'가 부류 없음). 줄 이름 `바꿀 장소`·`점심 장소`·`기준 장소`(`:747`·`:754`·`:763`)는 기존 `활동 장소`·`가는 편 출발지`와 같은 명사구 꼴이다. 맥락 줄 `고칠 일정 '…'`·`날짜 '…'`(`:944-945` → `:929`)도 조사가 없다. 모델 문구의 동사 `고치지`·`조회하지`·`등록하지`(`:956-958`)에 `않았어요`가 붙는 꼴은 문법상 맞다. 번역투는 찾지 못했다. 다만 같은 화면의 다른 문구(확인 버튼 "등록하기" D-1, 취소 말풍선 "그 등록은" D-2)가 도구 동사와 어긋난다.

**(2) 캡션이 참인가.** 이유를 대지 않는 문장이라 단일 정확 일치, 결과 1건, 5건 상한, 같은 이름 다른 좌표 모두에서 **카드가 처음 뜬 순간에는 참**이다(판정 `:3201-3216`은 결과가 있으면 언제나 unclear, 0건이면 카드가 없다). 캡션에 들어가는 질의는 비지 않는다 — `unclear`는 비지 않은 질의의 검색에서만 생긴다(`:3065-3068`). 거짓이 되는 순간은 사용자가 캡션의 권유대로 카드 안에서 다시 검색했을 때다(D-3).

**(3) 단일 출처.** 줄 이름은 `placeRow`(`:775`)를 지나는 공장 한 곳씩, 캡션은 `unclearPlaceNote` 한 곳, 맥락 줄은 `filledValueLabels` 한 곳, 도구 동사는 `pendingActionVerb` 한 곳이다(`grep -rnF` 결과 — 각 문구가 `Shared/`에 한 번씩, 드라이버의 단언만 따로). 예외는 D-7(중복 가드 두 벌 + `"등록하지"` 비교 리터럴)과 의도된 D-9(줄 이름 = 선언 설명)다.

**(4) 색·Theme.** 기준 대비 `AIAssistant.swift` diff의 추가 줄에서 `Color|Theme.|foregroundStyle|.font(|cornerRadius|.red|.green|.blue|opacity|#RRGGBB`를 찾은 결과 0건(grep exit 1). 뷰 파일 변경도 없다. 위반 없음.

**(5) 접근성.** 줄 컨테이너는 "줄 이름. 캡션"으로 읽힌다(`Shared/EditCardView.swift:160`) — 새 줄도 같은 경로라 "바꿀 장소. '스타벅스 강남점' 검색 결과예요…"로 읽힌다. 후보 칩은 "이름, 주소"(`:377`). 내부 토큰은 캡션에 닿지 않고(`:3062-3063`이 검색 전에 토큰을 푼다) 맥락 줄에서도 걸러진다(`:927`). 읽기에 거슬리는 것은 수정 카드의 ISO 날짜(D-4)와, 주소가 빈 같은 이름 칩의 같은 라벨(D-12, 가설)이다. 대괄호·괄호는 사용자 문구에 없다(`({names})`는 모델 문구 `:1014`에만 있다).

**(6) 카드 장수와 흐름.**
- 단발 등록: 제목·수단·여유·알림을 다 말하면 후보 카드 한 장, 아니면 실행 전 카드 → 후보 카드 두 장(`plan.md` §7). 두 장 자체는 실행 전 카드가 검색 없이 동기로 서는 구조 때문이라 이 카드에서 피할 수 없지만, 첫 카드가 둘째 카드가 물을 값을 "말씀하신 대로"로 적는 모순이 생긴다(D-6).
- 반복 + 점심: [반복 기간] → 출발지·목적지 후보 → 점심 후보, 최대 세 장. 점심이 마지막인 순서는 맞다 — 출발지·목적지가 정해져야 머무는 반복인지(점심을 쓰지 않는지) 알 수 있어서다(머무는 판정 `:2193` 뒤, 점심 해석 `:2258-2283`, D-4 (a)). 출발지·목적지가 검색 질의가 아니면 점심 카드 한 장만 더해진다.
- 조회 둘: 실행 전 카드가 없어 후보 카드 한 장 → 확인 → 답, 두 단계다. 카드가 떠 있는 동안 답 말풍선은 없고 카드만 보인다(`:453`). 그 카드의 머리말은 "몇 가지만 알려주세요", 버튼은 "등록하기"다(D-1).
- 막다른 길: 후보 5건이 다 틀려도 검색칸이 처음부터 열려 있어(`startsOpen` `:997`) 다른 이름으로 다시 찾을 수 있다 — 막다른 길은 아니다. 카드 안 검색이 0건이면 "후보를 찾지 못했어요. 다른 이름이나 주소로 …"가 뜨고 다시 칠 수 있다. 카드를 그만두는 방법은 새 말을 하는 것뿐이고 그 사실이 카드에 적혀 있지 않다(기존 동작). 입력칸을 비우면 원래 후보가 사라진다(D-3).

**(7) 확인 경로 문구.** D-14 — 문제 없음.

**(8) 운영자가 시뮬레이터에서 눈으로 볼 것** (코드 읽기로 증명할 수 없는 것만, 8개):

3. S-2에서 카드 검색칸에 `스타벅스 홍대`를 쳤을 때 캡션이 여전히 "'스타벅스 홍대점' 검색 결과예요"인지, 칸을 지우면 처음 후보가 사라지는지(D-3).
